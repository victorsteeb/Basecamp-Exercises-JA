> ### ⚠️ ローカル環境での実行（OneDrive・Dropbox・iCloud Driveは使用不可）
>
> 本演習は**お使いのPC上**で実行します。ローカルのPython環境、ローカルのファイル、ローカルのGitリポジトリを使用します。クラウド同期フォルダーは通常のローカルフォルダーとは異なるため、演習ファイルを配置すると正常に動作しません。`C:\dev\`、`~/projects/`、デスクトップなど、同期対象外のフォルダーに解凍またはクローンしてください。
>
> これは単なる注意喚起ではなく、仕組み上実際に起こる問題です。OneDriveの **Files On-Demand** が有効な場合、ファイルが実際にはディスク上に存在せず、開いた時点でダウンロードされるプレースホルダーになっていることがあります。エクスプローラー上では正常に見えるノートブックが途中までしか読み込まれないことがあり、そのまま上書き保存すると、元の内容が警告なく失われます。さらに、同期処理はセットアップで作成されるファイルとも競合します。インストール中に `.venv` 内の数千の小さなファイルをロックするほか、`.git` フォルダーを破損させることもあります。Microsoftのツール自体も、この点について警告を表示します。
>
> もう1点ご注意ください。APIキーはgitignore対象の `.env` に保存します。`.gitignore` によってGitへの混入は防げますが、OneDriveが企業のクラウドストレージへアップロードすることは**一切**防げません。
>
> **すでにOneDrive内に解凍してしまった場合：** フォルダーを同期対象外の場所へ移動し、`.venv` を削除したうえで、セットアップをやり直してください。その場での修復は行わないでください。

## APIキー
すべてのハンズオンセッションでAnthropicのAPIキーが必要です。設定にターミナルは必要ありません。まず、ノートブックのセットアップセルを一度実行してください。gitignore対象の **`.env`** ファイルが作成されます。このファイルを開き、`ANTHROPIC_API_KEY=` の後にキーを貼り付けて保存し、セルを再実行してください。緑色の **「✓ APIキーを確認しました」** バナーが表示されれば、接続は完了です。キーは `.env` に保存し、ノートブックのセルには記載しないでください（ノートブックはお客様のリポジトリに紛れ込むことがあるためです）。キーはカーネルを再起動しても保持され、リポジトリのルートに置いた `.env` 1つですべての演習に対応できます。

すべての演習に対して一括で設定する場合は、次の方法も利用できます。

```bash
export ANTHROPIC_API_KEY=your_key_here   # your shell, the VS Code terminal, or a local .env
```

## 実行環境
本ハンズオンは、ブラウザ上の簡易的な実行環境ではなく、皆さまご自身の開発環境で実行することを前提としています。チャット画面からコードをコピー＆ペーストして実行することは避けてください。

- **VS Code / Cursor**：フォルダーを開き、ノートブックを開く（Jupyter拡張機能を使用）か、ターミナルで `.py` を実行します。
- **Claude Code (CLI)**：リポジトリ内で `claude` を起動し、`.py` を実行するか、Claude Codeをペアプログラミングの相手として演習を進めます。
- **Claude Desktop**：概念の確認やデバッグの相談相手として、並行して開いておきます。

詳細な手順は、各セッションのREADMEをご参照ください。

## セットアップとトラブルシューティング

ノートブックは初回実行時に必要なパッケージをインストールし、制限の厳しい企業管理のPython環境（`externally-managed-environment` / PEP 668エラー、管理者権限のないマシン、プロキシ環境）でも動作します。問題が解決しない場合は、**[SETUP.md](SETUP.md)** をご参照ください。venvによる手順、VS Codeの「カーネルの選択誤り」、企業プロキシ経由のインストールを1ページにまとめています。あらかじめバージョンを固定した環境を構築しておく場合は、次のコマンドを実行してください。

```bash
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
