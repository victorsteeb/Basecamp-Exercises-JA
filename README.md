> ### ⚠️ OneDrive、Dropbox、iCloud Drive ではなく、ローカルで実行してください
>
> この演習は **お使いのパソコン上** で動きます。ローカルのPython環境、ローカルのファイル、
> ローカルのGitリポジトリを使います。クラウド同期フォルダは通常のローカルフォルダでは
> ないため、演習をそこに置くと動かなくなります。代わりに、普通のフォルダに解凍または
> クローンしてください。たとえば `C:\dev\`、`~/projects/`、デスクトップなどです。
>
> 理由は単なる用心ではなく、文字どおりの話です。OneDrive の **Files On-Demand** では、
> ファイルが実際にはディスク上にないことがあります。開いたときにダウンロードされる
> プレースホルダーだからです。エクスプローラーでは問題なさそうに見えるノートブックが
> 途中で切れた状態で読み込まれ、その上に保存すると、本当の中身が気づかないうちに
> 失われます。さらに、同期はセットアップが作るものとも衝突します。インストール中に
> `.venv` 内の何千もの小さなファイルをロックしますし、`.git` フォルダを完全に壊す
> こともあります。Microsoft 自身のツールもまさにこの点を警告しています。
>
> もう1点、知っておいてください。APIキーは gitignore 対象の `.env` に入ります。
> `.gitignore` がGitへの混入を防いでくれますが、OneDrive が企業のクラウドストレージに
> アップロードするのは **まったく** 防げません。
>
> **すでに OneDrive の中に解凍してしまった場合は？** フォルダをローカルの別の場所へ
> 移し、`.venv` を削除して、セットアップをやり直してください。その場で直そうと
> しないでください。

## APIキー
すべてのビルドアロングセッションで Anthropic のAPIキーが必要です。設定にターミナルは不要です。ノートブックのセットアップセルを一度実行すると、gitignore 対象の **`.env`** ファイルが作られます。それを開いて `ANTHROPIC_API_KEY=` の後ろにキーを貼り付け、保存して、もう一度実行してください。緑色の **「✓ API key verified」** バナーが出れば接続完了です。キーは `.env` に置き、ノートブックのセルには決して書きません（ノートブックはお客様のリポジトリに紛れ込みがちだからです）。カーネルを再起動してもキーは残り、リポジトリのルートに置いた `.env` 1つですべての演習をまかなえます。

すべてに対して一度だけ設定したい場合も、次の方法で問題ありません。

```bash
export ANTHROPIC_API_KEY=your_key_here   # your shell, the VS Code terminal, or a local .env
```

## 実行場所
これらのビルドアロングは、ブラウザ上の下書き用スペースではなく、ご自身の環境で実行することを想定しています。チャット画面からコードをコピー＆ペーストして実行するのも避けてください。

- **VS Code / Cursor**：フォルダを開き、ノートブック（Jupyter 拡張機能）を開くか、ターミナルで `.py` を実行します。
- **Claude Code (CLI)**：リポジトリ内で `claude` を起動し、`.py` を実行するか、Claude Code をペアパートナーにして演習を進めます。
- **Claude Desktop**：概念の確認やデバッグのためのAIペアパートナーとして、横に開いておきます。

正確な手順は、各セッションの README に書かれています。

## セットアップとトラブルシューティング

ノートブックは初回実行時に必要なものをインストールし、制限の厳しい企業管理のPython
（`externally-managed-environment` / PEP 668 エラー、管理者権限のないマシン、プロキシ）でも動きます。
行き詰まったら、**[SETUP.md](SETUP.md)** の1ページが解決策です。venv の手順、VS Code の
「カーネルの選び間違い」という落とし穴、企業プロキシ経由のインストールをまとめています。事前に
環境を固定しておきたい場合は次のようにします。

```bash
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
