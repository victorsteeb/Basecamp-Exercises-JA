# 評価の構築：ハンズオン

**Partner Basecamp参加者向けの資料です。** 研修資料としての複製・再配布はご遠慮ください。ここで扱うパターンは、皆さまのお客様案件で自由にご活用いただけます。

## 構築する内容
商品価格の検索と計算を行うシンプルなAIショッピングアシスタント `boutique` を対象に、評価スイートを構築します。エージェントはおおむね動作しますが、完全ではありません。評価駆動の体系的なアプローチにより、どこで、なぜ失敗するのかを正確に特定し、修正することが本演習の課題です。

## 主な学習内容
AIエージェントの評価の構築方法として、テストタスクの定義、採点者の作成、ハーネスの実行、結果に基づく的確な改善を学びます。「試して様子を見る」進め方から脱却し、お客様へのリリース前に数値で根拠を示せる、再現可能なフィードバックループを確立します。

## 実行方法

演習はリポジトリ内で進めてください。チャット画面からコードをコピーして使用しないでください。ターミナルでの設定は不要です。ノートブック冒頭の**セットアップ：Claudeへの接続**セルが非表示の入力欄でAPIキーを求め、接続が完了すると緑色の**「✓ APIキーを確認しました」**バナーを表示します。（環境変数 `ANTHROPIC_API_KEY` がすでに設定されている場合は、自動的に使用されます。）

### VS Code / Cursor（推奨）

1. **File → Open Folder**でこのフォルダーを選択します。
2. 表示された場合は、**Python**と**Jupyter**の拡張機能をインストールします。
3. [`Building_an_Eval.ipynb`](Building_an_Eval.ipynb) を開いて **Python 3**カーネルを選択し、**Shift+Enter**で各セルを実行するか、**Run All**を実行します（チャットのセルでは対話セッションが自動的に開始されます。先に進むには `quit` と入力してください。事前にそのセルで `INTERACTIVE_CHAT = False` に設定すると、評価のセクションまで直接進めます）。

### Claude Code（CLI）

このフォルダーに `cd` で移動し、Claude Codeとペアになって演習を進めてください。

```bash
cd day2/01_evals
claude                          # work the exercise with Claude Code as your pair
```

### Claude Desktop

AIのペアとして、横に開いたまま作業してください。編集しながら、セルの解説、エラーのデバッグ、次に加える変更の提案を依頼できます。

セットアップセルは、実際のAPI呼び出しでキーを検証します。緑色のバナーが表示されれば接続は完了しています。キーをセルに直接貼り付けないでください。
