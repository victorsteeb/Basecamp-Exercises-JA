# 評価 · ビルドアロング

**Partner Basecamp 参加者向けに作成しています。** 研修教材としての複製・再配布はできません。ただし、ここで学ぶパターンをお客様の案件で活用していただくのは自由です。

## 作るもの
商品の価格を調べて計算をする、シンプルなAIショッピングアシスタント `boutique` の評価スイートを作ります。エージェントは動きます。ただし、おおむねです。どこで壊れるのか、なぜ壊れるのか、どう直すのかを、評価駆動の体系的なアプローチで突き止めるのが皆さんの役割です。

## 主な学び
AIエージェントの評価の作り方です。テストタスクの定義、採点者の作成、ハーネスの実行、そして結果を使った的を絞った改善を学びます。「やってみて様子を見る」から、お客様にリリースする前に数字で示せる、再現可能なフィードバックループへと進みます。

## 実行方法

演習はリポジトリ内で進めてください。チャットウィンドウからコードをコピーして使わないでください。ターミナルでの設定は不要です。ノートブック先頭の**セットアップ：Claudeに接続する**セルが、非表示のプロンプトでAPIキーを尋ね、接続できると緑色の**「✓ API key verified」**バナーを表示します。（環境に `ANTHROPIC_API_KEY` がすでに設定されている場合は、自動的に使われます。）

### VS Code / Cursor（推奨）

1. **File → Open Folder** でこのフォルダを選択します。
2. 求められたら、**Python** と **Jupyter** の拡張機能をインストールします。
3. [`Building_an_Eval.ipynb`](Building_an_Eval.ipynb) を開いて **Python 3** カーネルを選び、**Shift+Enter** でセルを実行するか、**Run All** を実行します（チャットのセルは対話セッションを自動で開始します。先に進むには `quit` と入力するか、先にそのセルで `INTERACTIVE_CHAT = False` に設定すると、評価のセクションまで一気に進みます）。

### Claude Code（CLI）

このフォルダに `cd` して、Claude Code とペアでこの演習に取り組みます。

```bash
cd day2/01_evals
claude                          # work the exercise with Claude Code as your pair
```

### Claude Desktop

横に開いておき、AIペアとして使ってください。セルの説明、エラーのデバッグ、編集中の次の変更案などを頼めます。

セットアップセルは、実際のAPI呼び出しでキーを検証します。緑色のバナーが出れば接続できています。キーをセルに貼り付けないでください。
