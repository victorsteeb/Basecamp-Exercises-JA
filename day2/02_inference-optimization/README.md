# 推論最適化 · **The Margin Call** · ビルドアロング

**Partner Basecamp参加者向けに作成。** 研修資料としての複製・再配布は禁止です。ここで学ぶパターンをご自身のお客様案件で活用することは自由です。

## 取り組む内容
あるファームのデモチームが、勝ち取ったピッチの前夜に作った契約デューデリジェンスエージェント、**ClauseScan v0**を引き継ぎます。対象は、プライベートエクイティのお客様による買収案件のサプライヤー契約です（248,000件の契約群、合意済みSLAは精度 ≥ 90%、インタラクティブp50 ≤ 5s、売上原価（COGS）≤ 契約あたり$0.02）。v0は*正確*ですが、案件マージンを食いつぶすほど遅く、コストもかかります。

ラボは3幕構成です。

1. **計測と基準値の確立（パート1〜2）。** TTFT、TTC、OTPS、そして*キャッシュを考慮した*コストを測る計測ツールを作り、Haiku、Sonnet、Opusで最初のテストを実行します。
2. **診断と調整項目の習得（パート3〜4）。** v0を実行してスコアカードを読み、6つの最適化の調整項目を、メーターを回しながら1つずつ見ていきます。**プロンプトキャッシング · モデルルーティング · 構造化出力と出力の規律 · 往復の削減 + ストリーミング · キャッシュをウォームしてからの並列化 · 2速アーキテクチャ（Batch API）。**
3. **最適化スプリント（パート5〜6）。** スコア付きのリーダーボードに対してパイプラインを作り直し（精度でゲートするので、速くても間違っていれば0点です）、ホールドアウトセットで検証し、前提を明記したステアリングコミッティ向けの変更前後スライドを自動生成します。

## 主な学び
AIワークロードを「デモでは動く」から「ステアリングコミッティで説明責任を果たせる」状態へ持っていく方法です。まず測る。精度ゲートに照らして最適化する。そして、トークンの経済性を案件の経済性（単位あたりの売上原価、SLA準拠、マージン）に翻訳する。どの調整項目も、実際のお客様案件で交わす会話に直結します。

**スコアリング：** `SCORE = 50 × (baseline $ / your $) + 50 × (baseline p50 / your p50)`。精度が90%を下回ると0点になります。v0の指数は100です。リーダーボードの行はセッションのチャットに投稿してください。強い構成は400を超えます。

> 💸 予算メモ：全セルを実行すると、API利用料は約**$2〜4**かかります。大半は、わざと無駄の多いv0の基準値測定によるものです。それも学びの一部です。

## 実行方法

作業はリポジトリ内で行ってください。チャット画面からコードをコピーしないでください。キーを1回設定してから、実行環境を選びます。

```bash
export ANTHROPIC_API_KEY=your_key_here   # your shell, the VS Code terminal, or a local .env
```

### VS Code / Cursor（推奨）

1. **ファイル → フォルダーを開く** で、このフォルダーを選びます。
2. 求められたら、**Python**と**Jupyter**の拡張機能をインストールします。
3. [`Inference_Optimization.ipynb`](Inference_Optimization.ipynb)を開き、**Python 3**カーネルを選びます。**Shift+Enter**でセルを実行するか、**Run All**を使います。このノートブックは、**Run All**で最後まで通るように作られています。
4. ターミナルのほうがよければ、そのまま最後まで実行します：`python3 Inference_Optimization.py`

### Claude Code（CLI）

このフォルダーに`cd`し、最初から最後まで実行するか、Claude Codeと組んで演習に取り組みます。

```bash
cd day2/02_inference-optimization
python3 Inference_Optimization.py     # run straight through
claude                                # …or work the exercise with Claude Code as your pair
```

### Claude Desktop

AIのペアとして横に開いておきましょう。セルの説明、エラーのデバッグ、次の変更案を、編集しながら聞けます。

セットアップセルは、環境から`ANTHROPIC_API_KEY`を読み込みます（非表示入力のフォールバック付き）。キーをセルに貼り付けてはいけません。
