# 推論最適化：ハンズオン（**The Margin Call**）

**Partner Basecamp参加者向けの資料です。** 研修資料としての複製・再配布はご遠慮ください。ここで扱うパターンは、皆さまのお客様案件で自由にご活用いただけます。

## 演習の概要
自社のデモチームが、受注につながったピッチの前夜に構築した契約デューデリジェンスエージェント**ClauseScan v0**を引き継ぎます。対象は、プライベートエクイティのお客様による買収案件のサプライヤー契約です（契約群は248,000件、合意済みSLAは精度 ≥ 90%、対話型p50 ≤ 5s、売上原価（COGS）≤ 契約1件あたり$0.02）。v0は*正確*ですが、案件マージンを圧迫するほど遅く、コストも高くなっています。

本演習は3部構成です。

1. **計測と基準値の確立（パート1〜2）。** TTFT、TTC、OTPS、*キャッシュを考慮した*コストを計測するツールを構築し、Haiku、Sonnet、Opusで初期テストを実行します。
2. **診断と調整項目の習得（パート3〜4）。** v0を実行してスコアカードを確認し、6つの最適化の調整項目を、計測しながら1つずつ検証します：**プロンプトキャッシング · モデルルーティング · 構造化出力と出力の規律 · 往復の削減とストリーミング · キャッシュのウォームを伴う並列化 · 2速アーキテクチャ（Batch API）。**
3. **最適化スプリント（パート5〜6）。** リーダーボードでスコアを競いながらパイプラインを再構築し（精度でゲートするため、速くても誤りがあれば0点です）、ホールドアウトセットで検証したうえで、前提を明記したステアリングコミッティ向けの最適化前後の比較スライドを自動生成します。

## 主な学習内容
AIワークロードを「デモでは動く」状態から「ステアリングコミッティで説明できる」状態へ引き上げる方法を学びます。まず計測し、精度ゲートを満たしたうえで最適化し、トークンの経済性を案件の経済性（単位あたりの売上原価、SLA準拠、マージン）に置き換えます。いずれの調整項目も、実際のお客様案件での議論に直結します。

**スコアリング：** `SCORE = 50 × (baseline $ / your $) + 50 × (baseline p50 / your p50)`。精度が90%を下回ると0点になります。v0の指数は100です。リーダーボードの行はセッションのチャットに投稿してください。優れた構成であれば400を超えます。

> 💸 予算に関する注記：全セルを実行すると、API利用料は約**$2〜4**かかります。その大半は、意図的に無駄を多くしたv0の基準値測定によるものであり、これも学習内容の一部です。

## 実行方法

演習はリポジトリ内で進めてください。チャット画面からコードをコピーしないでください。キーを一度設定してから、実行環境を選択してください。

```bash
export ANTHROPIC_API_KEY=your_key_here   # your shell, the VS Code terminal, or a local .env
```

### VS Code / Cursor（推奨）

1. **ファイル → フォルダーを開く** で、このフォルダーを選択します。
2. 表示された場合は、**Python**と**Jupyter**の拡張機能をインストールします。
3. [`Inference_Optimization.ipynb`](Inference_Optimization.ipynb) を開き、**Python 3**カーネルを選択します。**Shift+Enter**でセルを実行するか、**Run All**を使用します。このノートブックは、**Run All**で最後まで実行できるように構成されています。
4. ターミナルで実行する場合は、次のコマンドで最後まで実行できます：`python3 Inference_Optimization.py`

### Claude Code（CLI）

このフォルダーに `cd` したうえで、最後まで一括で実行するか、Claude Codeとペアで演習に取り組んでください。

```bash
cd day2/02_inference-optimization
python3 Inference_Optimization.py     # run straight through
claude                                # …or work the exercise with Claude Code as your pair
```

### Claude Desktop

AIのペアとして、横に開いたまま作業してください。編集しながら、セルの解説、エラーのデバッグ、次に加える変更の提案を依頼できます。

セットアップセルは、環境変数から `ANTHROPIC_API_KEY` を読み取ります（見つからない場合は非表示の入力欄で入力を求めます）。キーをセルに直接貼り付けないでください。
