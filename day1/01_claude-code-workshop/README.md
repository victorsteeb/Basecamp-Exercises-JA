# Claude Code Workshop

**Partner Basecamp 参加者向けに作成しています。** 研修教材としての複製・再配布はできません。ただし、ここで学ぶパターンをお客様の案件で活用していただくのは自由です。

Claude Code を使って、稼働中の工場在庫管理システムを調べ、変更し、拡張します。システムは実際の Vue 3 フロントエンドと FastAPI バックエンドです。この演習は自由度が高く、唯一の正解はありません。自分で書いていないコードベースで、Claude Code を開発パートナーとして体験することが狙いです。

## 手順ガイド

- **ライブサイト（推奨）：** https://claude-code-workshop.netlify.app/ ：名前とワークショップコードは何を入力しても構いません
- **オフラインのバックアップ：** コンパニオンサイトが使えない場合は、このフォルダにある [`workshop-guide.pdf`](./workshop-guide.pdf) を開くと、手順をすべて確認できます。

この演習は、12のコアステップとエキスパートチャレンジで構成されています。
