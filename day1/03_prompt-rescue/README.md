**Partner Basecamp参加者向けに作成しています。** 研修資料としての複製・再配布はできません。ここで学ぶパターンを、ご自身のお客様向けの業務に活用することは自由です。

## 今回やること
あなたは、TechSupport Corpの技術コンサルタントとして呼ばれました。お客様の本番プロンプトは、サポートチケットを処理しています。優先度の分類、エンティティの抽出、回答の下書き作成です。整った入力ではうまく動きますが、乱雑な実世界のチケットではひどく失敗します。更新の打ち合わせは48時間後です。あなたの仕事は、このプロンプトをレスキューすることです。

## 主な学び
壊れたプロンプトを体系的に診断し、修正する方法を学びます。失敗ケースを調べ、根本原因（誤った優先度分類、ハルシネーションされたエンティティ、壊れたJSON出力）を特定し、組み込みの評価ハーネスで反復します。ハーネスは、実世界のテストケースに対して、あなたの修正をスコアで評価します。

## 実行方法

リポジトリの中で演習を進めてください。チャットウィンドウからコードをコピーして持ち出さないでください。下から環境を選びます。セットアップのセルが、APIキー（非表示入力）を尋ねて接続を確認するので、ターミナルは不要です。任意で、キーを一度だけ設定しておけば、毎回入力を求められなくなります。

```bash
export ANTHROPIC_API_KEY=your_key_here   # your shell, the VS Code terminal, or a local .env
```

### VS Code / Cursor（推奨）

1. **File → Open Folder** を選び、このフォルダを選択します。
2. 求められたら、**Python**と**Jupyter**の拡張機能をインストールします。
3. [`Prompt_Rescue_solo.ipynb`](Prompt_Rescue_solo.ipynb)を開き、**Python 3**カーネルを選びます。セルは **Shift+Enter** または **Run All** で実行します。

### Claude Code（CLI）

このフォルダに`cd`して、Claude Codeと一緒に演習を進めます。

```bash
cd day1/03_prompt-rescue
claude                            # work the exercise with Claude Code as your pair
```

### Claude Desktop

AIのペアとして、横で開いたままにしておきます。セルの説明、エラーのデバッグ、次の変更の提案を頼めます。

セットアップのセルは、環境から`ANTHROPIC_API_KEY`を読み込み（非表示の入力がフォールバックです）、実際のAPI呼び出しで検証し、接続できると緑色の**「✓ APIキーを確認しました」**バナーを表示します。キーをセルに貼り付けることは、決してしないでください。
