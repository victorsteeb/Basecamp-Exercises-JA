# プロンプト修復：ハンズオン

**Partner Basecamp参加者向けの資料です。** 研修資料としての複製・再配布はご遠慮ください。ここで扱うパターンは、皆さまのお客様案件で自由にご活用いただけます。

## 演習の概要
皆さまは、TechSupport Corpの技術コンサルタントとして本件に参画しています。同社の本番プロンプトは、サポートチケットの優先度分類、エンティティ抽出、回答案の作成を担っています。整った入力では正しく動作しますが、実際の雑多なチケットでは正しく機能しません。契約更新の打ち合わせは48時間後です。皆さまの役割は、このプロンプトを修復することです。

## 主な学習内容
不具合のあるプロンプトを体系的に診断し、修正する方法を習得します。失敗ケースを分析し、根本原因（優先度の誤分類、エンティティのハルシネーション、JSON出力の破損）を特定したうえで、組み込みの評価ハーネス（eval harness）を用いて改善を繰り返します。評価ハーネスは、実際の入力に基づくテストケースで修正内容を採点します。

---

## 実行方法

演習はリポジトリ内で進めてください。チャット画面からコードをコピーして使用しないでください。以下から実行環境を選択します。セットアップのセルがAPIキーの入力（非表示）を求めて接続を確認するため、ターミナルは不要です。任意で、次のようにキーを一度設定しておくと、以降は入力を求められません。

```bash
export ANTHROPIC_API_KEY=your_key_here   # your shell, the VS Code terminal, or a local .env
```

### VS Code / Cursor（推奨）

1. **File → Open Folder**を選び、このフォルダーを選択します。
2. 求められた場合は、**Python**と**Jupyter**の拡張機能をインストールします。
3. [`Prompt_Rescue_solo.ipynb`](Prompt_Rescue_solo.ipynb) を開き、**Python 3**カーネルを選択します。セルは**Shift+Enter**または**Run All**で実行します。

### Claude Code（CLI）

このフォルダーに `cd` で移動し、Claude Codeと協働しながら演習を進めてください。

```bash
cd day1/03_prompt-rescue
claude                            # work the exercise with Claude Code as your pair
```

### Claude Desktop

AIペアプログラマーとして、横に開いたまま作業してください。編集しながら、セルの解説、エラーのデバッグ、次に加える変更の提案を依頼できます。

セットアップのセルは、環境から `ANTHROPIC_API_KEY` を読み込み（フォールバックとして非表示の入力欄を使用）、実際のAPI呼び出しで検証します。接続できると、緑色の「**✓ APIキーを確認しました**」バナーが表示されます。キーをセルに直接貼り付けないでください。
